================================================================================
SCOPE
================================================================================

The repository provides runnable code, configurations, data artifacts, chain
files, and checksum manifests supporting the v4 manuscript:

Projective Correlation Theory: A Pregeometric Correlator Framework for
Emergent Spacetime Observables

The repository should be read as a reproducibility package. It does not convert
the Planck 2018 comparison into empirical confirmation. The manuscript treats
Planck 2018 as an archival-data consistency check; toy and synthetic outputs as
algorithmic checks; LVK ringdown as a null-control check; and the new D/NP/P/T
outputs as declared support, forecast, null, or future-work adjudication
artifacts.
